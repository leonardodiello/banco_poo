# Sobre o Projeto

O **banco_poo** é uma aplicação criada para praticar conceitos fundamentais de orientação a objetos utilizando Python, simulando funcionalidades comuns presentes em sistemas bancários.

O projeto busca reforçar conhecimentos como:

- Encapsulamento
- Abstração
- Herança
- Polimorfismo
- Manipulação de objetos
- Estruturação de sistemas

A aplicação permite simular operações financeiras e gerenciamento de contas bancárias através de uma interface simples via terminal.

---

# Funcionalidades

- Criação de contas bancárias
- Depósito em conta
- Saque de valores
- Transferência entre contas
- Consulta de saldo
- Manipulação de objetos bancários
- Estrutura orientada a objetos
- Interação via terminal
